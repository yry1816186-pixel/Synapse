# Synapse 实际定位

## 核心定位

**Synapse = 纯软件平台**

连接**已经有网络能力**的设备，不需要额外硬件。

## 能连接的设备（无需购买硬件）

### 1. WiFi 智能设备
- 智能插座（小米、TP-Link 等）
- 智能灯泡（Yeelight、Philips Hue WiFi 版）
- 智能空调（支持 WiFi 的）
- 智能摄像头
- 网络存储

**连接方式：** 设备 → WiFi 路由器 → Synapse

### 2. 蓝牙设备
- 手环（小米手环等）
- 温湿度传感器
- 智能锁（蓝牙版）
- 耳机

**连接方式：** 电脑/树莓派内置蓝牙 → Synapse

### 3. 网络服务
- 天气 API
- 日历服务
- 邮件服务
- 云存储

**连接方式：** HTTP/REST API

### 4. 电脑/手机
- 通过 App
- 通过 Web 界面
- 通过 API

## 不能连接的设备

需要购买额外硬件才能连接：
- Zigbee 设备（需要网关）
- 红外设备（需要红外发射器）
- RS485 工业设备（需要转换器）

## 与 Home Assistant 的区别

| 特性 | Home Assistant | Synapse |
|------|---------------|---------|
| 定位 | 智能家居中心 | 区域计算集群 |
| 范围 | 家庭 | 公司/园区 |
| 重点 | 设备连接 | 智能调度+协作 |
| 学习 | 规则引擎 | Hope 持续学习 |
| 多租户 | 无 | 有 |

## 实际应用场景

### 场景 1：办公室
```
已有设备：
- WiFi 投影仪
- 网络打印机
- 智能空调
- 员工电脑

Synapse 连接：
→ 统一管理
→ 智能调度
→ 能源优化
```

### 场景 2：机房
```
已有设备：
- 服务器
- 网络设备
- UPS 电源
- 监控系统

Synapse 连接：
→ 资源监控
→ 告警系统
→ 自动化运维
```

## 结论

**Synapse 是软件层面的"粘合剂"，连接已经有网络能力的设备。**

不需要：
- ❌ 购买网关
- ❌ 更换设备
- ❌ 安装硬件

只需要：
- ✅ 设备有网络
- ✅ Synapse 能访问
- ✅ API/协议支持

---

**这就是实际可行的定位。**
