#### Week 4: 实现真实场景

**场景：智能灯光控制**

1. 读取光敏电阻值
2. 当光线暗时自动开灯
3. 记录所有数据

**代码示例：**

```python
import RPi.GPIO as GPIO
import time

# 设置
GPIO.setmode(GPIO.BCM)
LIGHT_SENSOR = 17
LED = 18

GPIO.setup(LIGHT_SENSOR, GPIO.IN)
GPIO.setup(LED, GPIO.OUT)

while True:
    light = GPIO.input(LIGHT_SENSOR)
    if light == 0:  # 暗
        GPIO.output(LED, GPIO.HIGH)
    else:
        GPIO.output(LED, GPIO.LOW)
    time.sleep(1)
```
