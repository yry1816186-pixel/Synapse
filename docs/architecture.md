## 核心模块

### 1. 插件系统 (Plugin System)
- 32+ 生命周期 Hook
- 动态加载和卸载
- 热更新支持

### 2. 事件总线 (Event Bus)
- 发布-订阅模式
- 异步事件处理
- 中间件支持

### 3. 场景引擎 (Scene Engine)
- 触发器: 设备/时间/事件/手动
- 条件: 等于/大于/包含/正则
- 动作: 设备控制/场景/通知

### 4. Hope 持续学习模块
- 智能记忆系统
- 模式识别
- 行为预测
- 基于 Google Nested Learning

### 5. 设备抽象层
- 17+ 设备类型
- 10+ 协议支持
- 虚拟设备模拟

### 6. 多租户系统
- 租户隔离
- Casbin 权限控制
- 配额管理

## 技术栈

| 层级 | 技术 |
|------|------|
| API | FastAPI, Pydantic |
| 数据库 | PostgreSQL, SQLAlchemy |
| 缓存 | Redis |
| 消息 | MQTT (EMQX), NATS |
| 调度 | Celery, Temporal |
| 边缘 | eKuiper, KubeEdge |
| 权限 | Casbin |
| AI | 智谱 GLM, LangChain |

## 设计原则

1. **插件化** - 一切皆可扩展
2. **事件驱动** - 松耦合通信
3. **本地优先** - 核心功能离线可用
4. **持续学习** - 越用越智能
5. **多租户** - 企业级隔离
