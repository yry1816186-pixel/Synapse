**标题：** *SOMtime the World Ain't Fair: Violating Fairness Using Self-Organizing Maps*  
**arXiv ID：** [2602.18201](https://arxiv.org/abs/2602.18201)  
**开源代码：** [GitHub](https://github.com/JosephBingham/SOMtime)  
**关键词：** 公平性、自组织映射、无监督学习  

**核心发现：**
- **挑战传统假设：** 无监督表示并非对敏感属性中立

**影响：**
- 证明"无意识即公平"（fairness through unawareness）在表示层面失败
- 公平性审计必须扩展到机器学习管道的无监督组件

**研究规模：**
- 2,000 个 GitHub 仓库的分层样本（包含 Dockerfile）

**关键发现：**
- **仅 56% 能生成可构建镜像**

- **78.7% 可构建 Dockerfile 仍不可复现**

**根本原因：**
- 时间戳和元数据之外：
  - 未清理的缓存
  - 日志文件
  - 文档
  - 浮动版本号

**实践指南：**
- 提供 Dockerfile 编写指南
- 可用于未来的 linter 和 CI 检查
