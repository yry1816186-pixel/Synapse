### 1.1 Catastrophic Forgetting Resilient One-Shot Incremental Federated Learning (OSI-FL)

**论文编号**: 2602.17625v1  
**发布日期**: 2026-02-19  
**创新类型**: 持续学习 / 增量学习

#### 核心创新点

1. **单轮通信联邦学习** (One-Shot FL)
   - 传统联邦学习需要多轮通信,OSI-FL 仅需单轮即可完成模型训练
   - 使用冻结的 Vision-Language Model (VLM) 生成类别特定嵌入
   - 服务器端使用预训练的扩散模型合成数据分布

2. **选择性样本保留** (Selective Sample Retention, SSR)
   - 自动识别并保留每个类别-任务对中最具信息量的 top-p 样本
   - 基于样本损失动态选择代表性样本
   - 确保未来训练中包含历史任务的关键信息

3. **抗灾难性遗忘机制**
   - 通过 SSR 机制限制遗忘的上界
   - 支持类增量学习 (class-incremental) 和域增量学习 (domain-incremental)
   - 在三个基准数据集上超越传统联邦学习和单轮 FL 方法

#### 技术指标

| 指标 | 性能 |
|------|------|
| 通信轮次 | 1 轮 (vs 传统 FL: 10-100 轮) |
| 隐私保护 | 本地数据不出设备 |
| 增量支持 | 类增量 + 域增量 |
| 遗忘控制 | 通过 SSR 保证 |

#### Synapse 集成评估

**适用性**: ⭐⭐⭐⭐⭐ (5/5)

**集成路径**:
1. **短期 (1-3个月)**: 
   - 在 Synapse 的联邦学习模块中集成 OSI-FL 框架
   - 实现基于 VLM 的嵌入生成器
   - 部署 SSR 样本选择机制

2. **长期 (3-6个月)**:
   - 扩展到多模态数据 (IoT 传感器 + 图像)
   - 优化扩散模型的边缘设备部署
   - 开发自适应 top-p 参数调整算法

**预期收益**:
- 减少设备间通信开销 80-90%
- 支持增量式模型更新,无需完整重训练
- 增强隐私保护,符合边缘 AI 最佳实践

**技术风险**: 中等 (扩散模型计算开销大)

### 1.2 Guarding the Middle: Protecting Intermediate Representations in Federated Split Learning (KD-UFSL)

**论文编号**: 2602.17614v1  
**发布日期**: 2026-02-19  
**创新类型**: 隐私保护 / Split Learning

#### 核心创新点

1. **K-匿名差分隐私 UFSL** (K-anonymous Differentially Private UFSL)
   - 结合微聚合 (microaggregation) 和差分隐私技术
   - 保护 Split Learning 中的中间表示 (smashed data)
   - 防止数据重构攻击

2. **中间表示隐私增强**
   - 均方误差 (MSE) 增加 50%
   - 结构相似性 (SSIM) 降低 40%
   - 在四个基准数据集上验证

3. **效用-隐私平衡**
   - 在提升隐私的同时保持全局模型的效用
   - 适用于大规模大数据应用场景

#### 技术指标

| 指标 | 性能 |
|------|------|

| SSIM 降低 | 高达 40% |
| 模型效用 | 保持 |
| 隐私保证 | K-匿名 + DP |

### 1.3 EDRP: Enhanced Dynamic Relay Point Protocol for Multi-hop Wireless IoT Networks

**论文编号**: 2602.17619v1  
**发布日期**: 2026-02-19  
**创新类型**: IoT 设备调度 / 数据传播

#### 核心创新点

1. **链路感知 CSMA** (Link-Quality Aware CSMA, LQ-CSMA)
   - 根据实时链路质量估计动态限制退避延迟范围
   - 连接强度高的节点获得更短的延迟
   - 适应真实世界链路质量波动

2. **机器学习块大小选择** (ML-based Block Size Selection, ML-BSS)
   - 预测未来链路质量条件
   - 优化调整无速率编码的块大小
   - 减少开销,增强吞吐量

3. **分布式延迟定时器机制**
   - 基于发送方与其子节点之间的平均链路质量分配传输启动延迟
   - 优先高连接节点进行早期传输

#### 技术指标

| 指标 | 性能 |
|------|------|
| 吞吐量提升 | 平均 39.43% |
| 链路适应 | 实时 |
| 协议类型 | 多跳无线网络 |
| 应用场景 | 电网供电 IoT 节点 |

#### Synapse 集成评估

**适用性**: ⭐⭐⭐ (3/5)

**集成路径**:
1. **短期**:
   - 在 Synapse 的 IoT 设备通信模块中评估 EDRP 协议
   - 实现链路质量感知调度器
   - 开发 ML-BSS 算法原型

2. **长期**:
   - 扩展到异构网络环境
   - 集成到设备发现和拓扑管理模块
   - 优化边缘-云协同通信

**预期收益**:
- 提升多跳网络数据传播效率 30-40%
- 减少设备间通信延迟
- 增强网络鲁棒性

**技术风险**: 高 (需要硬件支持)
