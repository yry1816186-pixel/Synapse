## 一、Nested Learning / 持续学习

### 1.1 OSI-FL: 抗灾难性遗忘的单次增量联邦学习

**论文**: [Catastrophic Forgetting Resilient One-Shot Incremental Federated Learning](https://arxiv.org/abs/2602.17625)  
**发布日期**: 2026年2月19日  
**会议**: IEEE BigData 2025

#### 核心创新

OSI-FL 是首个同时解决**通信开销**和**灾难性遗忘**双重挑战的联邦学习框架：

1. **单次通信机制**: 使用冻结的视觉语言模型（VLM）提取类别特定嵌入，服务端通过预训练扩散模型合成数据
2. **选择性样本保留（SSR）**: 基于样本损失识别并保留每个类别-任务对的 top-p 最具信息量的样本
3. **遗忘边界控制**: 确保代表性保留样本在后续训练迭代中被纳入

#### 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                    OSI-FL 架构                          │
├─────────────────────────────────────────────────────────┤
│  客户端:  VLM (冻结) → 类别嵌入 → 单次上传              │
│  服务端:  扩散模型 → 数据合成 → 全局模型训练            │
│  SSR:    样本损失排序 → Top-p 保留 → 遗忘边界约束       │
└─────────────────────────────────────────────────────────┘
```

#### 关键指标

| 指标 | 性能 |
|------|------|
| 通信轮次 | 1 轮（传统 FL 需多轮） |
| 类增量准确率 | 超越传统 FL 基线 |
| 域增量准确率 | 超越现有单次 FL 方法 |

#### Synapse 集成建议

| 维度 | 评估 |
|------|------|
| 技术可行性 | ⭐⭐⭐⭐ 架构清晰，可直接参考 |
| 集成复杂度 | 中等（需引入 VLM/扩散模型） |
| 业务价值 | 高（解决边缘设备增量学习痛点） |

**推荐**: SSR 机制可独立应用于现有联邦学习模块，优先级高。

### 1.2 Fed-PLoRA: 异构联邦微调框架

**论文**: [Heterogeneous Federated Fine-Tuning with Parallel One-Rank Adaptation](https://arxiv.org/abs/2602.16936)  
**发布日期**: 2026年2月18日  
**会议**: ICLR 2026

#### 核心创新

Fed-PLoRA 解决了联邦学习中**客户端异构资源**导致的性能下降问题：

1. **并行一秩适配（PLoRA）**: 将传统多秩 LoRA 模块替换为多个并行的一秩模块
2. **Select-N-Fold 策略**: 在本地训练前将未训练的 PLoRA 模块折叠到预训练权重中，适应不同客户端资源
3. **噪声分析**: 提供初始化和聚合噪声的统一分析框架

#### 技术细节

```
传统 LoRA:    W + ΔW = W + BA   (B: n×r, A: r×n)
PLoRA:        W + Σ(B_i × A_i)  (多个 1-rank 模块并行)

Select-N-Fold:
  - 高资源客户端: 训练更多 PLoRA 模块
  - 低资源客户端: 折叠部分模块到基础权重，仅训练剩余模块
```

#### Synapse 集成建议

| 维度 | 评估 |
|------|------|
| 技术可行性 | ⭐⭐⭐⭐⭐ LoRA 已广泛使用 |
| 集成复杂度 | 低（可增强现有 LoRA 模块） |
| 业务价值 | 高（异构设备支持） |

**推荐**: 优先级最高，可直接集成到现有模型微调流程。

### 1.3 KD-UFSL: 联邦分割学习的中间表示保护

**论文**: [Guarding the Middle: Protecting Intermediate Representations in Federated Split Learning](https://arxiv.org/abs/2602.17614)  
**发布日期**: 2026年2月19日  
**会议**: IEEE BigData 2025

#### 核心创新

针对 U 形联邦分割学习（UFSL）中中间表示的隐私泄露风险：

1. **K-匿名差分隐私（KD-UFSL）**: 结合微聚合和差分隐私技术
2. **数据重建攻击防御**: 将重建图像的 MSE 提高 50%，结构相似度降低 40%
3. **隐私-效用平衡**: 在保护隐私的同时保持全局模型效用

#### Synapse 集成建议

适用于需要在边缘设备卸载部分计算的隐私敏感场景。

## 二、设备调度优化

### 2.1 可塑作业调度（Malleable Job Scheduling）

**论文**: [Evaluating Malleable Job Scheduling in HPC Clusters using Real-World Workloads](https://arxiv.org/abs/2602.17318)  
**发布日期**: 2026年2月19日

#### 核心创新

研究资源弹性调度，调度器可在运行时动态调整可塑作业的资源分配：

1. **五种调度策略评估**: 包括一种新颖的"保持首选资源分配"策略
2. **真实工作负载验证**: 基于 Cori、Eagle、Theta 超算的真实追踪数据
3. **显著性能提升**:
   - 作业周转时间降低 37-67%
   - 作业等待时间降低 73-99%
   - 节点利用率提升 5-52%

#### 关键发现

即使只有 20% 的可塑作业也能带来显著收益，鼓励将可塑性集成到资源管理中。
