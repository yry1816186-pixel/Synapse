## 核心优势

### 1. 极致轻量

| 平台 | 二进制大小 | 对比 OpenClaw |
|------|-----------|--------------|
| ARMv7 (树莓派) | 5.90 MB | ~99% 更小 |
| ARM64 (aarch64) | 6.20 MB | ~99% 更小 |
| x86_64 (PC/Mac) | 5.91 MB | ~99% 更小 |

### 2. 极低资源需求

| 资源 | ZeroClaw | OpenClaw | 节省 |
|------|----------|----------|------|
| **内存** | <5 MB | ~500 MB | **99%** |
| **磁盘** | ~6 MB | ~500 MB | **99%** |
| **CPU** | 低 | 中等 | **50%+** |
| **硬件成本** | $10 | $200+ (Mac mini) | **98%** |

### 3. 功能完整


## 集成建议

1. **树莓派边缘节点**
   - 用 ZeroClaw 替代 OpenClaw
   - 成本从 $200 降至 $35

   - 专注核心功能

5. **完整迁移**
   - Synapse 核心用 Rust 重写
